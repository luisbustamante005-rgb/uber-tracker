📋 Pasos para conectar Google Sheets

  1. Crea un Google Sheet nuevo: UberTracker
  2. Extensiones → Apps Script
  3. Borra el contenido y pega el código de apps-script.gs
  4. Guarda con Ctrl+S
  5. Implementar → Nueva implementación
  6. Tipo: Aplicación web · Ejecutar como: Yo · Acceso: Cualquier persona
  7. Copia la URL y pégala arriba
